# ZxBench v0.2.12

本版修复部署、请求取消和评分判定中的 bug，沿用 v0.2.11 的部署步骤、按需镜像准备和逐镜像下载地址。题库仍为 1.60.0，803 道来源题、920 个执行实例。

- 模型密钥在实际读写时读取已加载的环境配置，修复 ESM 导入早于 `.env` 加载导致配置密钥失效的问题。保留旧版默认密钥密文和旧版明文的读取能力；新的保存操作使用当前配置密钥，密文格式不变。升级时继续保留原 `.env`。
- 模型请求在调用前检查取消状态；完成后清理取消监听。流读取遵守硬时限，流取消回调最多等待 1 秒；空闲超时停止本次调用，避免重复发起已经停滞的生成请求。
- 没有代码围栏的 PHP 函数按真实花括号边界提取，保留空行、字符串、注释和 heredoc，排除函数结束后的解释文字。
- 语义复核识别英文句号，避免把相邻句的否定或条件附加到完整引文；小数及 URL 中的点仍保留在上下文中。已保存的原生工具轨迹以完成的最终正文为准，工具轮、被中断轮和协议错误不能作为最终答复。
- 工具世界提示允许按题意直接答复、澄清或拒绝，不再强制不必要的工具操作。
- 修复已审核冻结修订的重复读取次数及父目录状态判定。兼容范围限定在 8 个已核验的题目哈希；额外读取必须由成功事件、返回事实和状态共同证明，父目录只能从成功的 `mkdir(parents=True)` 推导。被修改的题目、禁止操作、改变的受保护事实、失败操作和未恢复错误仍失败。原始执行轨迹保持不变。

升级不会修改数据库中的旧成绩、自动重评、补测或调用模型/Judge。运行请求的 token 与思考预算沿用原有配置。

验证：完整工作区构建通过；2,103 项 Vitest 测试通过、218 项环境测试跳过；19 项题面/工具契约检查及 33 项部署测试通过。独立数据库上的真实服务验证了 `.env` 密钥加密与脱敏读取、0.2.12 版本、前端资源和全部 920 个题库定义。验证没有发起真实模型/Judge 请求。

部署及升级按 [README](../README.md) 执行；本版不需要重新下载已就绪的 Docker 镜像，也不需要整体镜像包。
