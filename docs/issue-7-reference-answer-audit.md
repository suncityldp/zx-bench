## 评分器问题与补丁

1. **容差历史语义不同。** 9月7日前 `tolerance=1` 被当作相对误差100%；以442717为gold，0到885434范围都可能满分。main 已给8道数值题加 `toleranceMode=absolute`，却保留004的错误gold。当前给出497776.30时，答案准确率0，正常格式的确定性总分仅10；给出442717则100。模型“算不出442717”不是独立证据，以上由算术与评分器实测共同证实。
2. **中间结果抢先。** v2按正则优先级找首个匹配，推导中的中文结论或`= 数字`可能早于最后的ANSWER行被提取。数值解析还会把日期截成2024等前缀。v3只读取最后一个非空行，并保留完整答案内容；该行必须是题面规定的ANSWER行，空的、无效的或不在末行的答案不会回退到前面的答案。
3. **多字段文本相似度掩盖错误。** v2对字符串gold使用包含关系/LCS，多字段数值没有真正应用数值容差。v3核对所要求的标签结构及每个数值分量，所有分量都通过才给答案分；将十进制数字规范化为有效数字与十进制指数后精确比较，不用二进制浮点数或epsilon掩盖数值差异，全部主推理题tolerance=0；不再因共享大量汉字而给高分。支持空白、全半角、粗体、合法千分位和单数值金额的万/亿单位；额外或错误单位、数字后缀、缺失分量会被拒绝。自由改写、字段重排或更复杂的数学等价表达并未普遍支持，题面已经要求固定答案格式；显式acceptedVariants用于已审查同义表述。
4. **Judge格式救援误用。** v2的低分长输出可能被标为formatBlindspot，将Judge权重抬到70%。补丁禁止严格答案契约以这种方式覆盖数值错误；普通评分和Judge补评路径同步。模拟Judge给满分时，错误答案仍低于及格线。真正的旧题答案缺陷不能通过仅补评Judge解决。

**按用户明确的判分原则收紧本地草案：** 允许497776.3、497776.30、497,776.30元、49.77763万元等数值相同的表示；497776.31或任何非零偏差都判错。需要近似计算的题目在题面规定四舍五入精度或向上取整规则，模型应按该规则给出固定答案，评分器不会替候选答案再次舍入以将其判对。各题统一写明最后一个非空行的ANSWER格式、字段名称和顺序，禁止答案行附带解释或多个候选值。

旧自定义题未声明`comparisonMode=strict`时保留原比较行为；主推理题通过明确的新版本启用严格模式，避免悄悄混用分数含义。

## 历史评测与榜单影响

代码证据表明污染可能双向存在：宽松容差/字符串相似度带来虚高，错误gold与最终答案误提取带来误扣分。不能把所有旧失分简单加90分，也不能宣布所有模型排名已经改变。

现有`ScenarioResult`保存scenarioVersion和graderVersion，但数据库表未保存core返回的scenarioHash或完整题面快照；ScenarioDefinition又会被upsert覆盖。历史summary、已生成AI报告都是存储结果，不会随JSON文件自动刷新。`latest`榜单直接使用run.summary中的分数，`best`按scenarioId跨run取高分，不按题目版本分组。因此仅改答案、只修改文件或只重跑一次，都不能保证旧分数消失。

补丁做法：

- 逐行检查本次34个推理题ID的scenarioVersion和graderVersion。旧版、缺少版本，或包含4道争议题的run，**整轮排除**，再进入latest/best计算；避免只删一题却继续使用旧summary或改变分母。原始行、分数与报告不覆写、不删库，不借用environmentError标签。
- 当前v3有效题可参与比较，不涉及这些推理题的其他运行正常保留；latest选最新可比run，best只汇总可比run。混合新旧版本的run仍被隔离，部分单题重试不能自动解除整轮限制。
- API返回被隔离run与原因，历史详情、榜单显示提示。质量检查会标明参考答案问题；旧题仅Judge补评会被阻止。4道非valid题也不能通过单题重试重新计分。
- 榜单基准题量只统计status=valid，避免4道暂停题被继续当作“缺失题”。

为说明量级：假定无Judge、34道原推理题完整运行，第四题难度权重2，原推理权重总和53，单题确定性分90分的偏差对应推理均分约`90×2/53=3.40`分；十维完整总分权重0.12时约0.41分。这是限定条件下的算术示例，不是对任何已存在run的实测修正；启用Judge、不同题集或多轮聚合需逐run重算。

**没有读取生产评测数据库或远端榜单数据，因此实际受影响的run数量、模型名单和名次变化尚未确定。** 代码层面的当前榜单隔离已经实现；历史总览、旧导出文件、既有AI报告、其他部署或独立排行站点不会在本次本地补丁中被回写。新旧题面不同的题目须重新生成模型回答，不能拿旧回答替换成v3题面后宣称是同一轮可比评测。
