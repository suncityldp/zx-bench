# ZxBench v0.2.13

本版包含 v0.2.12 之后的推理可靠性与容器执行修复。题库仍为 1.60.0，803 道来源题、920 个执行实例。

- 推理中继辅助模块处理连接重置、HTTP 错误、空闲超时及不完整 SSE；故障后停止接收请求，恢复需要显式验证。补充进程故障监测、通知去重和原子状态写入。低显存预留仅作诊断，不单独触发暂停。这些辅助模块不会自动部署中继或启动监控。
- 唯一受支持的冻结 Go 镜像引用使用一致的本地兼容别名完成缓存检查、构建和最终检查。其他 digest 保持原样，localImageOnly 仍禁止拉取或构建；镜像身份校验不放宽，兼容 tag 不代表与历史 digest 字节一致。
- 对同一容器的 inspect 最多查询三次，共享受剩余时间约束的查询预算，不重放候选程序。恢复后明确的启动或 daemon 状态错误仍否决；记录真实耗时和预算超限，进程终止等待不提供绝对墙钟保证。
- 仅 QuickJS v1 observation 在执行退出 0、无执行错误且严格观察协议完整可信时，可将持续查询故障记录为 warning 并继续原评分。错误答案仍失败；缺失、畸形或不可信证据保持未测。syntax、v2 和其他未适配路径保持 fail-closed。
- 最终结果保留固定枚举、限长脱敏的状态查询证据。来自 run 输出的错误分类仅为不可信诊断线索，不能凭候选伪造文本获得免扣分。

这些改动改善已验证的运行路径与故障证据，不证明报告者现场根因；没有重启 daemon 或复现未知部署拓扑。升级不会自动重评历史成绩，不修改冻结题目、旧答卷或数据库成绩。

验证：完整工作区构建与类型检查、无模型回归及部署诊断。发布提交的准确 CI 结果见 GitHub Actions；此前同一运行逻辑的固定程序 Docker 验证覆盖查询重试接线与 v2 集成，没有调用模型或 Judge。普通测试仍包含环境相关跳过项，不代表全环境覆盖。

按 [README](https://github.com/suncityldp/zx-bench/blob/v0.2.13/README.md) 升级。沿用既有固定镜像及 v0.2.11 镜像资产，本版不重发镜像、不更新 Docker latest，也不会自动部署。
