# HE-001｜维修后的恢复，能说明什么？

题面草案，待审核；未测试、未冻结评分标准，不计入现有成绩。不含参考答案。

以下材料均为虚构，只依据所给记录完成任务，不使用外部资料。

## D1｜现场事件

设备A42在9月6日高负载生产中触发温度停机。控制器保存的传感器S17最高读数为96℃，停机阈值为90℃。现场巡检表另记“外壳温度81℃”，测点在设备外壳，记录于停机后4分钟。S17测量的是设备内部冷却液。

## D2｜维修与复机

9月7日同一次停机检修中，工作人员将S17换为S29、清理冷却风道，并把控制软件从F3升级到F4。三项完成后才复机。随后连续五个班次没有再次触发温度停机；这些班次均采用此前高负载任务约六成的负载。

## D3｜拆下部件的检查

流转单确认送检件为A42拆下的S17。检查人员先在25℃恒温槽中测试S17和S29，两者读数均在校准允差内。随后在82℃恒温槽中将探头连接端置于高湿条件，独立校准温度计始终记录82±0.2℃；S17在四轮测试中均出现超过90℃的读数，S29四轮均未出现。除探头外，连接线、采集器和测试步骤相同，每轮交换先后顺序。

## D4｜控制器台架记录

测试人员将控制器接入上述82℃、高湿条件，分别测试F3、F4与S17、S29的四种组合。每种组合重复四轮。S17配F3、S17配F4均在每轮触发温度停机；S29配F3、S29配F4均未触发。独立温度计始终记录82±0.2℃。所有台架记录对应9月8日的实验室测试。

## D5｜现场环境与软件变更

A42安装位置平时较潮湿，但9月6日事件期间没有保存探头连接端的湿度记录，也没有独立的内部冷却液温度记录。F4变更说明记载增加了短时读数波动过滤；没有提供仅升级软件、保持其他现场条件不变的运行记录。

## D6｜拟发布的结论及其引用

维修负责人拟发布：

> “两份独立调查均证实：S17在9月6日发生漂移，是本次停机的唯一原因，设备当时并未真实过热。更换S17彻底消除了故障，F4升级和风道清理都没有作用。”

所引“实验室简报”摘录自D3、D4；所引“供应商服务通报”注明技术依据为该实验室简报，未附新增测量记录。
